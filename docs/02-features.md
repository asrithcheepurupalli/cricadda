# CricAdda — Feature Catalog

Features are grouped by layer. ✅ = core (your original idea), ⭐ = new idea to make it
even cooler. Phase numbers refer to the [roadmap](04-roadmap.md).

---

## 1. Accounts, Teams & Identity

| Feature | Description | Phase |
|---|---|---|
| ✅ Phone number login (OTP) | Zero-friction sign-in, no passwords | 1 |
| ✅ Create & save teams | Build a squad once, reuse forever; invite players by phone number | 1 |
| ⭐ Player profiles | Photo, batting/bowling style, jersey number, career stats | 1 |
| ⭐ Guest players | Add an unregistered friend by name; they claim the stats later when they sign up | 2 |
| ⭐ Team identity kit | Team logo, colors, and slogan — reflected on the big screen | 2 |
| ⭐ Player intro cards | When a batsman walks in, the screen shows their photo, nickname & stats — with optional walk-in music | 3 |

## 2. Screen & Pairing

| Feature | Description | Phase |
|---|---|---|
| ✅ Big turf screen | LED display behind bowler's end (and optional batsman's end) showing live match state | 1 |
| ✅ Code pairing | Screen shows short code + QR; enter it in the app to take control | 1 |
| ✅ Full phone control | Everything on screen is configurable from the paired phone | 1 |
| ⭐ Screen themes | IPL-style, classic scoreboard, minimal, neon night-mode — pick per match | 2 |
| ⭐ Multi-screen sync | Both-end screens + a lobby/café TV all show synchronized content | 2 |
| ⭐ Idle mode | Between bookings the screen shows turf branding, leaderboards, upcoming slots, and ads | 2 |
| ⭐ Controller handoff | Pass scoring control to another phone mid-match (umpire, next scorer) with one tap | 1 |
| ⭐ Spectator QR | A QR on screen lets anyone (parents, friends at home) follow live ball-by-ball on the web — no app needed | 2 |

## 3. Scoring — Manual

| Feature | Description | Phase |
|---|---|---|
| ✅ Ball-by-ball scoring | Big fast buttons: 0/1/2/3/4/6, W, wide, no-ball, byes, leg-byes | 1 |
| ✅ Full match rules | Custom overs, players per side, last-man-stands, joker rules, no-LBW — box cricket needs flexible rules | 1 |
| ⭐ Undo / edit any ball | Fix mistakes instantly; screen and stats recompute | 1 |
| ⭐ Smartwatch scoring | Umpire scores from a watch — taps without pulling out a phone | 4 |
| ⭐ Voice scoring | "Four runs", "wicket bowled" — hands-free scoring via speech recognition | 4 |

## 4. Scoring — Automatic (Sensors + AI Cameras)

| Feature | Description | Phase |
|---|---|---|
| ✅ Boundary sensors (4s) | Vibration/impact sensors on boundary walls & nets + IR triplines detect fours instantly | 3 |
| ✅ Camera detection (6s) | AI vision detects ball clearing the net/roof line; distinguishes 4 vs 6 | 3 |
| ✅ Auto run counting | Cameras track batsmen crossing the crease to count completed runs | 3 |
| ✅ Hybrid confirm mode | Auto-detected events appear as one-tap suggestions; scorer confirms or corrects | 3 |
| ✅ Manual override | Any auto event correctable in two taps — manual always wins | 3 |
| ⭐ Ball speed gun | Camera-based bowling speed on every delivery, shown on screen like TV | 3 |
| ⭐ Pitch map & wagon wheel | Auto-plotted bowling pitch maps and batting wagon wheels from ball tracking | 4 |
| ⭐ Smart stumps / LED bails | Bluetooth stumps that flash & timestamp on impact — run-out and bowled detection | 4 |
| ⭐ Run-out replay assist | Crease camera auto-clips the moment of a run-out for review on the big screen ("DRS-lite") | 4 |
| ⭐ No-ball detection | Front-foot camera flags overstepping | 4 |
